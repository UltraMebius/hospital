**表6 《2016 年欧洲心脏病学会心房颤动管理指南》对房颤导管消融及外科手术的建议**

| 建议 | 建议等级 | 证据级别 |
| --- | --- | --- |
| 导管消融建议用于下列有症状的阵发性房颤患者: 抗心律失常药物( 胺碘酮、决奈达隆、氟卡胺、普罗帕酮、索他洛尔) 治疗后仍有房颤复发并有症状者; 在有经验的中心，患者愿意接受房颤导管消融进行节律控制 | Ⅰ | A |
| 若有明确的房扑，或在房颤导管消融过程中出现房扑，应同时对房扑进行导管消融 | Ⅱa | B |
| 根据患者的意愿、获益、风险的综合评估，房颤的导管消融应作为预防房颤复发、改善阵发性房颤者症状的一线治疗选择，是抗心律失常药物外的另一选择 | Ⅱa | B |
| 所有行导管消融( Ⅱa B) 及外科消融( Ⅱa C) 的患者，术后均应服用OAC 至少8 周 | Ⅱa | B，C |
| 导管消融术后表现为成功恢复窦性心律的患者，若卒中高风险，仍应继续进行抗凝治疗 | Ⅱa | C |
| 计划行房颤导管消融的患者，应在围术期继续服用维生素K 拮抗剂( Ⅱa，B) 或NOAC ( Ⅱa，C) ，以保证抗凝效果 | Ⅱb | B，C |
| 导管消融应将通过射频或冷冻球囊隔离肺静脉作为目标 | Ⅱa | B |
| 在合并射血分数降低心衰的症状性房颤患者中，有可疑的心动过速性心肌病时，行房颤导管消融可改善症状及心功能 | Ⅱa | C |
| 存在与房颤相关心动过缓的患者，房颤导管消融是避免起搏器植入的可行手段 | Ⅱa | C |
| 如果症状性持续性房颤或长程持续性房颤患者，抗心律失常药物无效，综合评估患者自身的选择、获益及风险后，可由房颤心脏团队进行导管或外科消融 | Ⅱa | C |
| 如果房颤导管消融失败，可考虑外科微创的心外膜肺静脉隔离。应由有经验的房颤心脏团队做出决定 | Ⅱa | B |
| 对于复发的症状性持续性房颤或者导管消融术后的患者，在有经验的中心，可考虑行微创的迷宫术，以改善症状 | Ⅱa | C |
| 行心脏手术的患者，在评估手术风险及节律控制治疗获益后，可同时行迷宫术( 双心房更佳) ，以改善房颤相关症状 | Ⅱa | A |
| 行心脏手术的无症状房颤患者，可考虑同时行双心房迷宫术及肺静脉隔离术 | Ⅱb | C |

注: OAC，口服抗凝药物; NOAC，新型口服抗凝药物; 房颤，心房颤动; 房扑，心房扑动; 心衰，心力衰竭
