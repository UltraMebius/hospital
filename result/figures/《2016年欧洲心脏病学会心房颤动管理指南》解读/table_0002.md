**表2 《2016 年欧洲心脏病学会心房颤动管理指南》对房颤患者预防卒中建议**

| 建议 | 建议等级 | 证据水平 |
| --- | --- | --- |
| 所有CHA₂DS₂-VASc 评分≥2 分的男性房颤患者，均建议使用OAC | Ⅰ | A |
| 所有CHA₂DS₂-VASc 评分≥3 分的女性房颤患者，均建议使用OAC | Ⅰ | A |
| CHA₂DS₂-VASc 评分= 1 分的男性房颤患者，可根据患者的个体情况及患者本人的意愿，给予OAC | Ⅱa | B |
| CHA₂DS₂-VASc 评分= 2 分的女性房颤患者，可根据患者的个体情况及患者本人的意愿，给予OAC | Ⅱa | B |
| 维生素K 拮抗剂( 维持INＲ2 ～3 或更高) 被建议用于有机械瓣或中-重度二尖瓣狭窄的患者 | Ⅰ | B |
| 房颤使用OAC 者，如无NOAC( 阿哌沙班、达比加群酯、依度沙班、利伐沙班) 禁忌证，应首选NOAC，次选维生素K 拮抗剂 | Ⅰ | A |
| 如果患者使用维生素K 拮抗剂，应密切监测INＲ，并使TTＲ尽可能高 | Ⅰ | A |
| 如患者使用维生素K 拮抗剂，当依从性良好，TTＲ不满意时，若无NOAC 禁忌证，建议换用NOAC; 或根据患者自身意愿换用NOAC( 如人工瓣膜) | Ⅱb | A |
| 合用OAC 和抗血小板药物将明显提高房颤患者的出血风险，若无明确使用抗血小板药物的适应证，应避免合用抗血小板药物 | Ⅲ | B |
| 无论男性还是女性房颤患者，若无卒中危险因素，不应使用OAC 或抗血小板药物 | Ⅲ | B |
| 无论卒中风险高低，不建议单独使用抗血小板药物用于房颤的卒中预防 | Ⅲ | A |
| 不建议在机械瓣( B 级证据) 或中-重度二尖瓣狭窄( C 级证据) 的房颤患者中使用NOAC( 阿哌沙班、达比加群酯、依度沙班、利伐沙班) | Ⅲ | B，C |

注: NOAC，新型口服抗凝药物; OAC，口服抗凝药物; INＲ，国际标准化比值; TTＲ，治疗范围时间; 房颤，心房颤动
